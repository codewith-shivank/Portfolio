# Portfolio

A responsive, single-page portfolio scaffold built with React, TypeScript, Vite, and Tailwind CSS. It uses the supplied MONODRIFT reference for visual direction while keeping profile, project, skill, and contact content empty until it is provided.

## Run locally

```bash
npm install
npm run dev
```

## Validate and build

```bash
npm run lint
npm run build
npm run preview
```

## Structure

- Hero with an empty profile-image area
- Empty skills and project sections
- Profile and approach sections ready for content
- Disabled contact-form presentation (it does not send messages)
- Lenis smooth scrolling with reduced-motion support

No image assets are currently wired into the portfolio sections. The existing `src/assets/hero.png` file is retained but unused.
